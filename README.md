# C++ If-Else Age Check

A beginner-friendly C++ program that demonstrates the use of **if-else statements**.

## Description

The program asks the user to enter their age and checks whether they are **18 or older**.

- Age ≥ 18 → You are an adult
- Age < 18 → You are not an adult


## Example

```text
Enter your age: 20
You are an adult
```
